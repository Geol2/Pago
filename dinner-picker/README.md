# 🌙 저녁 뭐 먹지?

저녁 메뉴를 랜덤으로 골라주는 프로그램입니다. 표준 라이브러리만 쓰므로 설치할 게 없습니다.

## 실행

```bash
python dinner.py              # 대화형 메뉴 (카테고리 선택 가능)
python dinner.py --pick       # 전체에서 바로 하나 추천
python dinner.py -c 한식 일식  # 특정 카테고리에서만 추천
python dinner.py --list       # 카테고리별 메뉴 목록 보기
```

## 기능

- 🎲 돌림판 애니메이션으로 메뉴 추천
- 📂 카테고리: 한식 / 중식 / 일식 / 양식 / 분식 / 치킨·야식 / 아시안
- 🧠 최근에 먹은 메뉴는 잘 안 나오게 가중치 적용 (`.dinner_history.json`에 기록)
- 📜 최근 먹은 메뉴 조회

## 메뉴 추가/수정

`dinner.py` 상단의 `MENUS` 딕셔너리만 고치면 됩니다.
